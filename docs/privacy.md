# Privacy Policy

Effective date: June 23, 2026

This policy explains how the Video Editing Hub Discord server and **Video Editing Hub Official** bot use Discord data.

The bot is built for the Video Editing Hub community and is intended to run only in the Video Editing Hub Discord server. It is not a general-purpose public bot.

## What data the bot processes

The bot may process Discord data when members use server features or when staff configure moderation/server tools.

This can include:

- Discord user IDs, role IDs, channel IDs, message IDs, thread IDs, and server IDs
- member join dates and role membership needed for cooldown roles, temporary roles, staff permissions, and job-board access
- message content in configured workflows, such as Verified Jobs submissions, job reports, testimonial feedback, scammer-report broadcasts, ad/forum automation, and staff message-management tools
- message attachments or uploaded files when a feature needs them, such as Verified Jobs reference images, report screenshots/evidence, or attachments copied by staff message-management tools
- job-board information submitted by users, such as job descriptions, budgets, payment details, reference links, image URLs, uploaded reference files, application/report metadata, and review outcomes
- testimonial information submitted by users, such as ratings, job type, feedback, submitter/editor IDs, and related thread/message IDs
- direct messages the bot sends to users about moderation, scammer bans, job approvals/rejections/holds, withdrawals, or other workflow status updates
- bot configuration set by staff, such as enabled channels, role IDs, retention settings, moderation/report channels, and feature toggles
- bot logs needed to operate, debug, and audit server features

## How the data is used

Data is used only to operate Video Editing Hub server features, including:

- moderation, scammer protection, and staff review workflows
- new-member cooldown roles and temporary role management
- staff permission checks and role/channel administration
- Verified Jobs submissions, reviews, publishing, reports, applications, tokens, and strike tracking
- testimonials and forum/thread lifecycle management
- ad responses, auto-publish, auto-thread, keep-alive, and auto-close features
- message move/copy tools used by staff to organize server content
- troubleshooting, security, abuse prevention, and audit logs

The bot does not sell Discord data, use it for advertising profiles, or use it to train, fine-tune, or improve machine-learning or AI models.

## Data storage and retention

Some data is stored outside Discord on Video Editing Hub-operated infrastructure so the bot can provide persistent server features. Stored data is primarily kept in SQLite databases, JSON configuration files, and operational logs.

Retention depends on the feature and is not always limited to 30 days:

- cooldown and temporary role records are kept until the role workflow expires or is cleaned up
- Verified Jobs records are kept for review, audit, report handling, duplicate prevention, strike tracking, and job-board maintenance, then may be cleaned up according to configured maintenance settings
- job applications, job reports, and related moderation/review records may be kept while needed for safety, dispute handling, audit history, or abuse prevention
- testimonials and related thread records are kept so completed job feedback and thread lifecycle state remain available
- staff configuration is kept while the feature remains configured
- operational logs are kept as needed for operation, troubleshooting, abuse prevention, and security review

Users or authorized server administrators may request deletion of stored activity data as described below. Some data may need to be retained when required for security, abuse prevention, moderation records, dispute handling, legal obligations, or to protect the integrity of server safety systems.

## Data sharing

Stored bot data is not sold. Access is limited to authorized Video Editing Hub operators and server staff as needed to run and moderate the community.

The bot uses Discord APIs to operate inside the server. User-submitted content may also remain visible in Discord channels, threads, DMs, webhooks, embeds, Discord-hosted attachments/CDN URLs, or logs depending on the feature used and staff configuration.

Some features download Discord-hosted attachments temporarily in order to re-upload them to Discord review threads, forum posts, reports, or copied messages. The bot may store the resulting Discord attachment/CDN URLs when needed for the workflow.

## AI and machine learning

Video Editing Hub Official does **not** use Discord message content, member data, or other Discord user data to train, fine-tune, or improve AI or machine-learning models.

## Security

Access to production bot data is restricted to authorized service infrastructure and operators. The project periodically reviews stored data, retention, and operational access as part of Discord compliance and server maintenance.

## Changes to this policy

This policy may be updated as bot features or Discord requirements change. The latest version will be published in the Video Editing Hub documentation.
